AI-Powered Communication Assistant
This project implements a basic AI-powered communication assistant designed to process support emails. It filters emails based on keywords, extracts key information, performs sentiment analysis, prioritizes urgent emails, and generates draft responses using a placeholder LLM.

Features
Email Filtering: Filters emails based on keywords in the subject line.
Information Extraction: Extracts sender, subject, body, and date/time.
Sentiment Analysis: Categorizes emails as Positive, Negative, or Neutral.
Urgency Prioritization: Identifies urgent emails based on keywords and assigns a priority.
Prioritization Queue: Processes urgent emails first.
Draft Response Generation: Generates context-aware draft replies using a placeholder LLM.
Basic Dashboard Simulation: Displays processed emails and their draft responses in a structured format.
